# HeadscaleClient v0.2.0

本版本统一了应用及各平台安装器的版本号，包含 Wails beta.23 升级、macOS
统一安装流程和近期设备列表改进。GitHub 标记为预发布，供安装体验和实机验收。

## 下载

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `headscaleclient-0.2.0-windows-amd64-installer.exe` |
| macOS Apple Silicon（M 系列） | `headscaleclient-0.2.0-macos-arm64-installer.pkg` |
| macOS Intel | `headscaleclient-0.2.0-macos-amd64-installer.pkg` |
| Linux x64，Ubuntu 24.04 / Debian 13 系列 | `headscaleclient-0.2.0-linux-amd64.deb` |

发布附带 `SHA256SUMS.txt` 校验值。Mac 不再区分独立版和 GUI-only 下载；每种
芯片一个 PKG，自动复用已有服务，或在没有服务时安装自带服务。

## 主要变化

- 应用“关于”、Windows 文件/安装器、Mac 应用/安装包和 Linux 包统一为 0.2.0。
  新增版本一致性校验，避免发布号更新但安装后仍显示旧版本。
- Wails Go、CLI 和前端运行库升级至 `v3.0.0-beta.23`。保留 Go `1.26.5`
  和 Tailscale `1.102.2`，不改变隧道内核和 ACL 策略。
- macOS 安装时检测服务：复用外部服务且不覆盖；只更新本产品管理的服务；
  没有服务才注册自带服务；检测到两套服务时明确提示冲突。
- macOS 设置页说明服务来源及共享账号/网络设置，区分服务不可达、权限不足、
  接口不兼容；安装向导补充中英文说明与检测提示。
- 保留设备分组、进入设备页自动刷新、主机名与局域网地址展示等近期改进。
- 修复 Linux DEB 打包时架构变量未展开的问题。

## 升级说明

安装前请从托盘或菜单栏退出 HeadscaleClient，仅关闭窗口可能仍在后台运行。
更新本产品管理的服务时保留账号及配置。复用外部 Tailscale 意味着共享它的
账号和网络设置，请避免同时从两个界面修改设置。

若从外部 Tailscale 切换为独立模式，先按原服务自己的流程卸载，再运行同一
个 PKG；不会自动迁移外部身份，可能需要重新登录。

## 验证范围与限制

发布前验证包括三平台构建/测试、Windows 安装器版本与启动检查、Mac 双架构
首次安装/服务复用/卸载/旧版升级，以及 Linux DEB 版本和内容检查。
具体执行结果记录在仓库的 `docs/verification/RELEASE-0.2.0.md`。

Windows 尚无可信发布者签名；Mac PKG 未签名，应用为 ad-hoc 签名，尚未 Apple
公证。Mac 构建目标为 macOS 12+，CI 在 macOS 15 运行。官方网络扩展版本、
真实 OIDC 登录、休眠唤醒、网络切换，以及 Linux 真实 systemd 主机安装仍需
实机验收。请勿全局关闭系统安全保护。
