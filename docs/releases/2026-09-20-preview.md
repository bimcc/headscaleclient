# HeadscaleClient preview — 2026-09-20

## 更新

- Wails Go、CLI、前端运行库同步升级到 `v3.0.0-beta.23`。
- 保持 Go `1.26.5` 和 Tailscale `1.102.2`；不改变网络内核、ACL 或登录机制。
- Windows AMD64 安装包重新构建，保留中英文安装、完成后运行及现有服务保护。
- 新增 macOS Apple Silicon / Intel 独立 PKG：包含客户端和 launchd 网络服务，
  不需要安装官方 Tailscale GUI。也提供复用现有服务的 GUI-only ZIP。
- 修复原有 Linux DEB 打包路径中的架构变量未展开问题。

## 选择下载

| 文件 | 用途 |
| --- | --- |
| `headscaleclient-amd64-installer.exe` | Windows x64 安装包 |
| `headscaleclient-macos-arm64-installer.pkg` | Apple Silicon（M 系列）独立安装包 |
| `headscaleclient-macos-amd64-installer.pkg` | Intel Mac 独立安装包 |
| `headscaleclient-macos-<arch>-gui-only.zip` | 仅 GUI，需已有兼容 Tailscale 服务 |
| `*-SHA256SUMS.txt` | 下载文件校验值 |

macOS 独立 PKG 会拒绝检测到的官方 Tailscale.app / Homebrew 服务冲突，
不会擅自卸载另一套服务。已有服务的用户请选择 GUI-only 版，或先自行移除
原服务后安装独立版。升级前请从菜单栏退出 HeadscaleClient。

## beta.20 兼容性

移除的是旧的原生 WebView2 加载器，改由纯 Go 实现；Windows 仍需要
WebView2 Runtime，安装器继续保留它的检查/引导。macOS 支持没有被移除。
本项目没有使用被移除的加载接口或需要额外启用的 macOS 私有 API。

## 验证与限制

- Windows、macOS、Ubuntu CI 全部通过；62 项前端测试及 Go 测试/静态检查通过。
- Windows 新二进制已做后台启动及 WebView2 子进程检查。
- 两种 Mac 芯片均通过原生构建、安装、本地 API 读写、服务重启、覆盖安装
  保留状态、GUI 启动、服务卸载检查。
- Windows 尚无可信发布者签名；macOS 应用为 ad-hoc 签名，PKG 未签名且
  尚未 Apple 公证。请勿因此全局关闭系统安全保护。
- Mac 构建目标为 macOS 12+，CI 验证环境为 macOS 15。真实 Headscale/OIDC
  登录、休眠唤醒、网络切换和下载文件的 Gatekeeper 行为仍需实机验收。
- 这是预览发布，不覆盖已有 `v0.1.0` 正式发布；应用内部版本仍为 `0.1.0`。
