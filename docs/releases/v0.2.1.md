# HeadscaleClient v0.2.1

本版本将 Wails 从 beta.23 调整为 **v3.0.0-beta.20**。针对 0.2.0 Windows
安装包的安全软件提示，完成安装包内容对比及 beta.8、beta.20 对照构建；用户
反馈两个对照版本均不再出现原提示，因此选用 beta.20 发布维护版本。

## 主要变化

- Wails Go 依赖、CLI、前端运行库及诊断信息统一固定为 beta.20，并增加一致性校验。
- 应用及 Windows、macOS、Linux 安装包版本统一为 0.2.1。
- 保留当前功能、Go 1.26.5 和 Tailscale 1.102.2；继续支持设备分组、自动刷新、
  中英文界面、托盘快捷操作，以及按现有规则安装或复用网络服务。

## 下载

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `headscaleclient-0.2.1-windows-amd64-installer.exe` |
| macOS Apple Silicon | `headscaleclient-0.2.1-macos-arm64-installer.pkg` |
| macOS Intel | `headscaleclient-0.2.1-macos-amd64-installer.pkg` |
| Linux x64，Ubuntu 24.04 / Debian 13 系列 | `headscaleclient-0.2.1-linux-amd64.deb` |

附带 `SHA256SUMS.txt`。旧版 0.2.0 保留原文件和校验值，本次作为新的正式版本发布。

## 升级与验证

安装前从托盘或菜单栏退出 HeadscaleClient，再运行对应平台安装包。更新本产品
管理的服务时保留账号及配置；复用外部 Tailscale 服务时继续共享其账号和网络设置。

用户复测针对 beta.20 对照包；0.2.1 因更新版本信息而重新构建，校验值不同。
安全软件判定可能随环境及规则更新变化，本次结果不代表所有安全软件的检测结论。
Windows 尚无可信发布者签名；Mac 应用为 ad-hoc 签名，PKG 未签名且未公证。
Mac 真实账号登录、休眠/漫游以及 Linux 真实 systemd 主机安装仍属单独实机验收范围。

具体构建、测试和安装包校验结果见
[发布验证记录](https://github.com/bimcc/headscaleclient/blob/main/docs/verification/RELEASE-0.2.1.md)。
