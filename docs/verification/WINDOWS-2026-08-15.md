# Windows Verification: 2026-08-15

This report records the first native MVP verification. It intentionally omits
account names, node names, IP addresses, authentication URLs, and API keys.

## Environment

- Windows amd64
- Go `1.26.5`
- Wails `v3.0.0-beta.8`
- Node.js `24`
- pnpm `11.21.0`
- Installed `tailscaled` `1.102.2`
- Test Headscale `v0.29.3` on Linux amd64
- Optional Headplane `0.7.0` used only for read-only server observation

Headplane is not a runtime, authentication, build, or deployment dependency of
HeadscaleClient. No administrator credential is stored by the application.

## Automated checks

- Wails bindings generated: 1 service, 12 methods, 18 models, and 4 events.
- All Go package tests passed.
- `go vet ./...` passed.
- Frontend tests passed: 4 files and 39 tests.
- Strict TypeScript and the production Vite build passed.
- `go tool wails3 build` produced `bin/headscaleclient.exe`.
- The verified daemon preparation step checked the MSI hash, three runtime-file
  hashes, and all Authenticode signers.
- NSIS produced the unsigned independent Windows machine installer.

## Native smoke checks

- The application opened at its configured `960 x 680` window size.
- The UI read live LocalAPI state from the installed daemon; it did not use
  fallback or demonstration data.
- Chinese text, local-device data, connection state, and network preferences
  rendered correctly.
- A second process exited with code 0 while the original process remained.
- Closing the window with close-to-tray enabled hid the window and kept the
  process running.
- Starting the executable again restored and focused the original window.
- Isolated silent install copied the client, daemon, Wintun, provenance, and
  licenses while leaving the existing external service path unchanged.
- Isolated uninstall removed only the test product directory and again left
  the external service path unchanged.
- Native screenshot:
  `native-windows-final.png` in the local Codex visualization output directory.

## Headscale environment checks

- The configured HTTPS control endpoint was reachable.
- `/health` returned a passing health result.
- `/version` reported Headscale `v0.29.3`.
- No user, machine, route, ACL, DNS, or key mutation was performed.
